# Swaminathan & Devi — Silver Jubilee Website

A static, responsive invitation website.

## Files
- `index.html` — website
- `assets/` — family photographs

## Before publishing
1. Create a Google Form for RSVP.
2. Add the Google Form URL to `GOOGLE_FORM_URL` near the bottom of `index.html`.
3. (Optional) Replace the placeholder form handoff with a prefilled Google Forms entry URL if you want the website fields to populate the Google Form automatically.
4. Upload the contents of this folder to a GitHub repository.
5. Import that repository into Vercel. No build command is needed; use the static/Other preset and leave the output directory as the project root.

The RSVP section is intentionally secondary. At present it shows a preparation message until a real Google Form URL is added; it does not pretend to save responses.
